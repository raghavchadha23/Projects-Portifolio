## 📘 Projects Overview

### 🚉 [Railway Track Simulator](projects/railway-simulator)
Simulates real-time train movements using multithreading, mutexes, and condition variables in C.  
Focuses on synchronization, memory management, and concurrent resource allocation.  
**Tech:** C, POSIX Threads, Mutexes, Condition Variables  
**Status:** Completed 

---

### 🗓️ [ICS Calendar Parser](projects/ics-parser)
Parses `.ics` calendar files into human-readable output, handling recurring and overlapping events.  
Includes custom data structures and efficient event indexing.  
**Tech:** C, File I/O, Data Structures  
**Status:** Completed 

---

### 🌐 [Simple Web Server (SWS)](projects/simple-web-server)
Implements a TCP-based server supporting both persistent and non-persistent HTTP connections, serving multiple concurrent clients.  
Tested with Wireshark and tcpdump.  
**Tech:** Python, Sockets, TCP, Wireshark, tcpdump  
**Status:** Completed
